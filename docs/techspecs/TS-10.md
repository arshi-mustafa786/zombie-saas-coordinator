## Story Summary
As an IT Ops Manager, I want the system to automatically find all Zapier and Make workflows that depend on Trello, so we know what breaks.

## Vertical Scope
This story is a complete vertical slice:
- **DB layer:** Firestore collection `dependency_graphs`
- **Service layer:** ADK Tool functions (`scan_zapier`, `scan_make`, `build_dependency_graph`) on the **Integrator Agent**
- **API layer:** Cloud Run — invoked by root orchestrator after HITL gate passes (parallel with Architect Agent)
- **UI layer:** N/A

## Agent Architecture (Google ADK)

This story defines the **Integrator Agent** and all its tools:

```python
from google.adk.agents import Agent


def scan_zapier(app_name: str) -> dict:
    """Connects to the Zapier API (OAuth 2.0) and queries for all
    active zaps that contain the specified app as a trigger or action.
    For each matching zap, records: zap name, trigger condition,
    action, and downstream app dependencies. Handles pagination
    for accounts with >100 zaps."""
    ...


def scan_make(app_name: str) -> dict:
    """Connects to the Make (Integromat) API (OAuth 2.0) and queries
    for all active scenarios referencing the specified app.
    For each scenario, records: name, trigger module, action modules,
    and downstream dependencies."""
    ...


def build_dependency_graph(workflows: list[dict]) -> dict:
    """Compiles all discovered Zapier and Make workflows into a
    dependency graph showing: Source App → Automation Hub → Target Apps.
    Identifies critical workflows (daily syncs, customer-facing automations).
    Flags workflows that will break if the source app is decommissioned.
    Stores the graph in Firestore."""
    ...


integrator_agent = Agent(
    name="integrator_agent",
    model="gemini-2.0-flash",
    description="Scans automation hubs (Zapier, Make) for workflow dependencies on target apps",
    instruction="You are the Integrator Agent. Your job is to discover all automation "
    "workflows that depend on a given SaaS application. Use scan_zapier and "
    "scan_make to find dependent workflows, then build_dependency_graph to "
    "compile the results into a risk assessment.",
    tools=[scan_zapier, scan_make, build_dependency_graph],
)
```

## Module Interface Contract (draft)
| Tool Function | Signature | Returns | Raises | Docstring |
|---------------|-----------|---------|--------|-----------|
| `scan_zapier` | `scan_zapier(app_name: str) -> dict` | `{"workflows": list}` | `ApiError` | Fetches zaps referencing the app. |
| `scan_make` | `scan_make(app_name: str) -> dict` | `{"scenarios": list}` | `ApiError` | Fetches Make scenarios referencing the app. |
| `build_dependency_graph` | `build_dependency_graph(workflows: list[dict]) -> dict` | `{"graph": Graph, "critical": list}` | `None` | Compiles dependency mapping. |

## Acceptance Criteria
- Integrator Agent connects to Zapier and Make APIs via OAuth 2.0
- Queries for all active workflows containing the target app as trigger or action
- For each workflow, records: name, trigger, action, downstream dependencies
- Identifies critical workflows (daily syncs, customer-facing automations)
- Generates dependency graph stored in Firestore
- Flags workflows that will break if app is decommissioned
- All API calls and dependencies logged to Cloud Audit Logs

## Test Outline
- [ ] Happy path: Finds 1 Zapier zap and 1 Make scenario correctly.
- [ ] Edge case: API pagination for >100 zaps.
- [ ] Security: OAuth token securely retrieved from Secret Manager.
- [ ] Security: API response injection attack prevented.
- [ ] Error path: Zapier API unauthorized (401) — tool returns error dict.

## Story Summary
As a Technical Lead, I want the system to clearly identify when a behavioral contract cannot be satisfied, and propose a concrete remediation.

## Vertical Scope
This story is a complete vertical slice:
- **DB layer:** Firestore collection `semantic_mismatches`
- **Service layer:** ADK Tool function (`generate_remediation`) on the **Architect Agent** using **Gemini Pro**
- **API layer:** Cloud Run — invoked as the final step of the Architect Agent's pipeline
- **UI layer:** N/A

## Agent Architecture (Google ADK)

This is the **capstone tool** of the Architect Agent. It processes incompatible simulation results and proposes remediations using Gemini Pro's code generation:

```python
def generate_remediation(simulation_result: dict) -> dict:
    """For each behavioral contract classified as 'Incompatible'
    by simulate_transition, generates a Semantic Mismatch Report:
    1. Original contract: The source automation rule
    2. Target capability gap: What Asana cannot do natively
    3. Remediation hypothesis: Concrete fix proposal
       (e.g., a Zapier/Make webhook with code skeleton)
    4. Risk assessment: Impact and third-party dependency risk

    Uses Gemini Pro to generate working code skeletons for
    proposed webhook remediations. Stores report in Firestore
    and flags as High-Risk in the consolidation proposal."""
    ...
```

The `architect_agent` now has its full toolset: `[extract_trello_rules, parse_automation_rule, diff_schemas, classify_mapping, simulate_transition, generate_remediation]` — 6 tools, within the ≤7 deep module limit.

## Acceptance Criteria
- Architect Agent generates Semantic Mismatch Report for incompatible contracts
- Report contains: original contract, target capability gap, remediation hypothesis
- Proposes concrete remediation with Zapier/Make code skeleton generated by Gemini Pro
- Includes risk assessment for proposed remediation
- Flags mismatch as High-Risk in consolidation proposal in Firestore
- Notifies IT Ops of manual review or custom development requirements

## Test Outline
